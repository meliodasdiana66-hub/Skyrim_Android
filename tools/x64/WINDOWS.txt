Read-only checks for the local SkyrimSE.exe. Do not copy the EXE, DLLs, BSA, or ESM.
The harness now sets Windows stdin/stdout to binary mode itself, before fread. Delete any local clang.exe wrapper that force-included _setmode; leaving it on PATH hides this copy of clang.
Dry-run uses only the Python standard library. Do not install packages for that step.
Neither command launches the game. A verified_match is Windows-or-host x64 versus Unicorn, not ARM64 Android and not gameplay.
