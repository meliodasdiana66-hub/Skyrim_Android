Build it from this directory with the same clang used for the tests:

  clang -std=c11 -O2 -Wall -Wextra -Werror pe_data_map.c pe_data.c guest_mem.c ae_abi.c ae_dispatch.c ae_iat.c -o pe_data_map

The command above leaves every import unresolved. --bind-iat is opt-in. It writes a guest token into each IAT slot before the image is sealed, then seals. A modeled import gets a call token. Every other import gets a trap token, not a success value. The entry point is still not called, the file is not modified, and no host pointer is stored. On this EXE that is 2 call tokens (GetLastError, GetCurrentProcessId) and 597 traps. SetLastError is not imported.

Read-only search for small routines whose only calls are KERNEL32 GetLastError or GetCurrentProcessId. It does not execute a graph and does not call the entry point. eligible may be 0.
